# 5-class scam_category 실험 결과 — 2026-06-09

평가: seed-level group split (그룹 단위 = `(source_ref, seed_text)`, train/val 누수 차단)
모델: mDeBERTa-v3-base-mnli-xnli + LoRA, ep10 bs7 lr2e-5 max_len512, early stopping(patience2, macro_f1)
범위: **실험 결과 문서화 전용** — active_models.json 변경 없음 · 학습 결과 모델 적용 없음 · push 없음

> 결론: 3차례 group-split 벤치마크를 통해 5-class scam_category 구조가 **macro_f1 0.883 → 0.957** 로 안정화됨.
> 핵심 동력은 ① romance-crypto 재라벨(D2 금전메커니즘) ② 위장형 투자·가상자산 seed 추가.

## 0. 벤치마크 3 run 개요

| run | 시점 | 데이터 변화 | val(그룹) | macro_f1 | accuracy |
|---|---|---|---:|---:|---:|
| **R1 baseline** | 이전 세션 | 재라벨 전 | 240 (12그룹) | 0.8830 | 0.8792 |
| **R2 relabel** | 오늘 | B버킷 재매핑 + romance-crypto 4개 재라벨 | 280 (14그룹) | 0.9271 | 0.9250 |

> ⚠️ **비교 caveat**: 데이터가 늘며 val 구성이 매 run 달라짐(투자 support 60→80→100). 절대 오분류 수보다 **클래스 내 정규화 지표(recall)** 가 가장 신뢰할 비교치이며, 단일 split 분산도 존재. 그럼에도 방향성은 3 run 일관되게 개선.

## 1. 재라벨 전후 성능 변화 (R1 → R2)

romance-crypto/nft 4개를 D2 금전메커니즘 기준으로 **로맨스 스캠 → 코인 사기** 재라벨 + B버킷 재매핑.

| 지표 | R1 baseline | R2 relabel | 변화 |
|---|---:|---:|---|
| 전체 macro_f1 | 0.8830 | 0.9271 | **+0.044** |
| 전체 accuracy | 0.8792 | 0.9250 | +0.046 |
| 투자·가상자산형 F1 | 0.7965 | 0.8859 | +0.089 |
| 관계·지인 사칭형 F1 | 0.7912 | 0.9440 | **+0.153** |

- **관계·지인 F1 +0.153** 이 최대 개선 — 코인 미끼가 섞여 오염됐던 관계·지인 클래스가 "순수 관계 기반 사기"로 정제됨(recall 0.90→0.98).
- romance-crypto 4개가 관계·지인에서 투자·가상자산으로 이동하며 경계 혼동 감소.

## 3. 투자·가상자산형 recall 변화 (3 run 추이)

| run | precision | **recall** | F1 | support |
|---|---:|---:|---:|---:|
| R1 baseline | 0.849 | **0.750** | 0.797 | 60 |
| R2 relabel | 0.957 | **0.825** | 0.886 | 80 |
| R3 disguise | 0.960 | **0.970** | 0.965 | 100 |

→ recall **0.750 → 0.825 → 0.970** (+0.220). 클래스 내 정규화 지표라 val 구성 변화의 영향이 가장 적은 신뢰 지표.

## 4. 투자 → 기관/관계/거래 오분류 변화

투자·가상자산형 true 샘플이 다른 category로 새는 건수(confusion matrix 투자 행):

| run | 투자→기관 | 투자→관계 | 투자→거래·취업 | (투자→투자 정답) | support |
|---|---:|---:|---:|---:|---:|
| R1 baseline | 0 | **15** | 0 | 45 | 60 |
| R2 relabel | 6 | 6 | 2 | 66 | 80 |
| R3 disguise | **0** | **0** | **3** | 97 | 100 |

- **R1→R3 으로 투자→관계 15→0, 투자→기관 0(유지) 또는 6→0 소거.** 위장형 기관·관계 seed가 정확히 의도대로 경계 누수를 제거.
- R2 에서 투자→기관 6 이 잠깐 나타난 건 val 구성 변화에 따른 것이며, R3 에서 기관형 위장 seed 추가로 0 으로 소거.

## 5. 남은 약점 — 거래·취업형처럼 보이는 투자·가상자산형 3건

R3 에서 유일하게 남은 누수: **투자·가상자산형 true 100건 중 3건이 거래·취업형으로 오분류** (3.0%).

- 부업/취업 위장 seed 3개(apptech-reward / review-usdt / datawork-wallet)를 넣었지만 이 누수는 거의 안 줄었음(R2 2.5% → R3 3.0%).
- **원인**: 미션포인트·리워드·충전 유도 수법이 정상 부업/알바·중고거래 사기와 표면 구조가 너무 유사. "보상 적립 → 출금 위해 충전" 패턴이 거래·취업형과 어휘적으로 겹침.
- **개선 여지**: 거래·취업↔투자 경계 위장형 seed 추가 보강(부업 위장 코인 수법 다양화) — 단, 현재 우선순위 낮음(3% 수준, 단일 누수).
